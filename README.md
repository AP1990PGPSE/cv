# Your Name — CV website

A responsive, single-page CV website. Edit `index.html` to replace the example text, email address, and profile/project links with your own details.

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Open the Pages URL shown in the repository settings after GitHub finishes publishing.

The site uses plain HTML and CSS, so it needs no build step or dependencies.
